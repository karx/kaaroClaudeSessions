1 · Pipeline

A JSONL byte becomes a note only after four translations. Adapters never hear audio. resolveSonic is the first sonic-aware function, and in the browser it still lives inside 14-pulse-audio.js — not the Event Registry.

0
RAW JSONL

Harness transcript. One file (or tree) per session. Experience layer never reads this.

1
ADAPTER → NORMALIZEDRECORD

Per-harness hooks/adapters/*.mjs. Sonic-unaware. Emits kind, tool, category, tokens, text.

2
PULSE TRANSFORMER

toolNameToKey(tool, category) stamps data.key. Every NR emits ≥1 pulse. Unknown kinds become unknown, never silence.

▶ Canonical keys: read write edit grep_glob agent bash_git bash_run bash_other web other
3
RESOLVESONIC

Seven axes: instrument, pan, brightness, volMult, octave, sendAmt, pitch degree. Mapping rules first-match-wins. Then timbre / mixer.

4
SCHEDULER → COALESCE → OSCILLATOR

Live: 80 ms batch, snap to next beat. Replay: 24 ms cohort, no grid. coalesceVoices caps oscillators at 4; ghosts still draw on the DAW.

2 · Seven axes

Color is grammar. Each axis carries one meaning. Changing an axis for decoration breaks the encoding.

01INSTRUMENT
  • ▶ Category / timbre. File=plucked, system=perc, AI=bell, tokens=flute, failure=buzz.
02PAN
  • ▶ Stereo place. Mutation left, observation/delegation right. Harness bias added then clamped ±1.
03BRIGHTNESS
  • ▶ Voice lowpass cutoff Hz. Sharp new state ≈10 kHz. Warm cache ≈800 Hz. Only tokens is dynamic.
04VOLMULT
  • ▶ Importance / velocity. Write 1.30, chirp 0.35, api_error 1.40. Mixer family gain multiplies after.
05OCTAVE
  • ▶ Register vs project root. Agent intended +1 (registry); compact −2; tokens −1. Identity without leaving the scale.
06SENDAMT
  • ▶ Reverb send. Agent 0.40, web 0.28, compact 0.30, tokens 0.00. Cognitive distance, not wetness for beauty.
07DEGREE / HZ
  • ▶ Pitch inside the scale. Default path_hash(where). Words: floor(word_count/15) clamped to scale length. Tokens: always degree 0.

Project root

MIDI roots cycle [60, 62, 64, 65, 67, 69, 71, 72, 74, 76, 77, 79] from the project’s color index. Same file path hashes to the same degree in every project; the tonic moves so projects don’t unison. Harness pan bias is added after SPATIAL then clamped ±1: pi −0.15 · antigravity +0.15 · grok +0.25.

playPulse applies a second volume stage the matrix does not show: tool_call uses instrument default when volMult is 1 else 0.42 × volMult; tokens min(0.11, 0.04+log1p(output/300)×0.028) × volMult; words 0.11 × volMult; cognition 0.12 × volMult. Then mixer family gain (no-op when fam is null).

6 · Cognitive pressure

A master-bus automation, not a per-voice axis. Twenty-sample rolling cache ratio plus 10-second event density drive a lowpass on the whole mix. Heavy cached context + dense pulses → the session dulls.

7 · Scheduler + polyphony

This is the current change set. A simultaneous burst used to stack N harps on C4. Now the flush runs coalesceVoices: under the cap, unisons spread into a scale chord; over the cap, high-salience keys keep a voice and the rest of each family collapse to a chord (or one percussion hit). Oscillator count never exceeds 4. Ghosts still paint on the DAW.

Two clocks

LIVESSE PULSES80 MS
  • ▶ Batch 80 ms, then snap onto the next beat (BPM grid, default 120).
  • ▶ Stagger ≤12 ms across the audible chord so attacks don’t phase-cancel.
REPLAY_audioImmediate24 MS
  • ▶ Session replay from GET /api/audio/:id. No beat grid — same-timestamp pulses must still cohort so coalesce can chord them.
  • ▶ DAW playhead uses voicesSoundingAt(_scheduledVoices, audioNow); ring ts rewritten to scheduled wall time.

Salience order

When slots run out: tool_error/api_error 100 · write 90 · edit 80 · words/human_turn 70 · agent 65 · bash_* 55–45 · read 30 · tokens 12 · thinking 10. Percussion piles become one hit with a log2 volume boost, never a snare chord.

8 · Live engine vs registry

CONTEXT.md says the Event Registry is the single source of truth. The browser still has its own SPATIAL, COG_SOUND, AUDIO_FAMILIES, and DEFAULT_SETTINGS.instruments. Server-side audio-sim.mjs reads the registry. Replay still calls playPulse, so you hear the browser tables even when /api/audio computed a different sonic.

9 · Production path

The uncommitted change set wires a trace-shaped audio endpoint. Same locate → read → simulate → JSON pattern as /api/trace. mtime+preset cached.

HTTP
GET /api/audio/:session_id?preset=cognitive-flow

surface/http-routes.mjs strips query, resolves the file via 8-char slug, calls buildAudio.

SVC
AUDIO-SERVICE

readSessionRecords → simulateSession (registry + presets) → payload of {relMs, event, hz, sonic, data}.

DAW
19-DAW-BUILDER REPLAY

LOAD fetches the payload. PLAY sets _audioImmediate=true and fires playPulse(ev.event, data) on a speed-scaled timeout. Precomputed sonic/hz are not what you hear — the browser re-resolves.

▶ Dual encoding is audible: sim used the registry; the speaker uses 14-pulse-audio.js.
TAKEAWAY

Sonic encoding is a spatial grammar: left mutates, right observes, dull means cached or failing, bright means new, reverb means a cognitive branch left the room. The live engine in 14-pulse-audio.js is what you hear. The Event Registry is what the design says you should hear. Until those tables collapse into one, documentation that only cites the registry is lying about the mix.
